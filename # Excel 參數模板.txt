# Excel 參數模板

## 📋 使用說明

這是用於批量設定交易參數的 Excel 模板。你可以在 Excel 中編輯參數，然後直接複製貼上到網頁介面。

## 📊 格式說明

### 格式 1：包含層數欄（推薦）

| 層數 | 多倉 | 空倉 | 加倉門檻(%) | 獲利目標(%) |
|------|------|------|-------------|-------------|
| 1    | 100  | 100  | 0.5         | 0.5         |
| 2    | 200  | 200  | 0.5         | 0.45        |
| 3    | 400  | 400  | 0.5         | 0.4         |
| 4    | 800  | 800  | 0.5         | 0.35        |
| 5    | 1600 | 1600 | 0.5         | 0.3         |

### 格式 2：不包含層數欄

| 多倉 | 空倉 | 加倉門檻(%) | 獲利目標(%) |
|------|------|-------------|-------------|

## 📝 使用步驟

### 1. 在 Excel 中準備數據

1. 開啟 Excel
2. 貼上上方的預設參數
3. 根據需求修改數值
4. 可以增加或減少行數

### 2. 複製數據

**選項 A - 不包含表頭：**
- 只選擇數據行（不包含第一行表頭）
- 按 Ctrl+C 複製

**選項 B - 包含表頭：**
- 選擇包含表頭的所有數據
- 按 Ctrl+C 複製
- 系統會自動忽略表頭

### 3. 貼上到網頁

1. 開啟交易機器人網頁
2. 點擊參數表格區域（表格內任意位置）
3. 按 Ctrl+V 貼上
4. 確認數據是否正確

## ⚠️ 注意事項

### 數據驗證

貼上後請檢查：
- ✅ 層數是否連續
- ✅ 金額是否遞增
- ✅ 百分比是否在合理範圍（0.01-100）
- ✅ 沒有空白或錯誤數值

### 常見錯誤

❌ **錯誤 1：使用逗號作為小數點**
```
錯誤：0,5
正確：0.5
```

❌ **錯誤 2：包含貨幣符號**
```
錯誤：$100
正確：100
```

❌ **錯誤 3：包含百分比符號**
```
錯誤：0.5%
正確：0.5
```

❌ **錯誤 4：數據欄位不完整**
```
錯誤：100  100  0.5  (缺少獲利目標)
正確：100  100  0.5  0.5
```

## 🔢 Excel 公式參考

如果想用公式自動生成遞增數據：

### 倍增金額（馬丁格爾策略）
```excel
A2: 100
A3: =A2*2
往下拖曳複製
```

### 遞減獲利目標
```excel
E2: 0.5
E3: =E2-0.05
往下拖曳複製
```

### 完整公式範例
```excel
# A列（層數）
A2: 1
A3: =A2+1

# B列（多倉）
B2: 100
B3: =B2*2

# C列（空倉）
C2: =B2

# D列（加倉門檻）
D2: 0.5

# E列（獲利目標）
E2: 0.5
E3: =MAX(0.05, E2-0.05)
```

## 💾 儲存模板

建議將常用的參數組合儲存為不同的 Excel 檔案：

- `參數_保守型.xlsx`
- `參數_激進型.xlsx`
- `參數_平衡型.xlsx`
- `參數_測試用.xlsx`

這樣可以快速切換不同的交易策略。

## 🎓 進階技巧

### 批量測試不同參數

1. 在 Excel 中準備多組參數
2. 使用不同的工作表（Sheet）
3. 測試時切換不同的 Sheet
4. 記錄每組參數的表現

### 參數優化

1. 記錄每次交易的結果
2. 分析哪些參數組合效果最好
3. 逐步優化調整
4. 建立自己的最佳參數庫
