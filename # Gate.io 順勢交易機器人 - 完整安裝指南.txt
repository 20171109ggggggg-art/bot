# Gate.io 順勢交易機器人 - 完整安裝指南

## 📦 系統需求

- Python 3.8 或以上版本
- pip 套件管理工具
- 穩定的網路連線

## 🔧 安裝步驟

### 1. 安裝 Python 套件

```bash
pip install flask requests
```

### 2. 建立專案資料夾結構

```
trading_bot/
├── gate_trading_bot.py          # 主程式
├── templates/
│   └── index.html               # 網頁介面
└── trading_bot.db               # 資料庫 (自動生成)
```

### 3. 放置檔案

1. 將主程式碼儲存為 `gate_trading_bot.py`
2. 建立 `templates` 資料夾
3. 將 HTML 介面儲存為 `templates/index.html`

## 🚀 啟動步驟

### 1. 啟動伺服器

```bash
python gate_trading_bot.py
```

看到以下訊息表示成功：
```
* Running on http://0.0.0.0:5000
```

### 2. 開啟網頁介面

在瀏覽器中打開：
```
http://localhost:5000
```

## 🔑 Gate.io API 設定

### 測試網 API (建議先用這個)

1. 前往 https://testnet.gate.com/zh/myaccount/profile/api-key/manage
2. 註冊測試網帳號
3. 創建 API Key：
   - 勾選 **永續合約交易** 權限
   - 設定 IP 白名單 (可選)
4. 複製 API Key 和 Secret

### 領取測試幣

1. 登入測試網
2. 前往資產頁面
3. 點擊「領取測試幣」獲取 USDT

## 📱 Telegram 通知設定 (可選)

### 1. 建立 Telegram Bot

1. 在 Telegram 搜尋 `@BotFather`
2. 發送 `/newbot` 創建機器人
3. 設定名稱，獲得 **Bot Token**

### 2. 獲取 Chat ID

1. 在 Telegram 搜尋 `@userinfobot`
2. 發送任意訊息，獲得你的 **Chat ID**

### 3. 啟用通知

在網頁介面填入：
- Bot Token: `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`
- Chat ID: `123456789`

## 🎯 使用流程

### 1. 填寫 API 資訊

- **API Key**: 從 Gate.io 複製
- **API Secret**: 從 Gate.io 複製
- **環境**: 選擇「測試網」

### 2. 選擇交易對

- 點擊「載入永續合約」
- 選擇 1-5 個交易對 (建議先選 1-2 個測試)
- 推薦: `BTC_USDT`, `ETH_USDT`

### 3. 設定參數

根據圖表選擇層數 (1-5)，每層對應不同的：
- **多倉金額**: 做多時的投入金額
- **空倉金額**: 做空時的投入金額
- **加倉門檻**: 價格變動多少 % 時加倉
- **獲利目標**: 獲利多少 % 時平倉

**建議新手設定：**
- 選擇層數 1 或 2
- 金額設定小一點 (10-50 USDT)

### 4. 啟動機器人

點擊「▶️ 啟動機器人」，系統會：
1. 初始建立多空倉位
2. 開始監控價格變化
3. 自動執行加倉/平倉邏輯
4. 發送 Telegram 通知 (如有設定)

### 5. 監控運行

- **當前倉位**: 實時顯示多空倉位狀態
- **交易記錄**: 查看所有交易歷史
- **刷新按鈕**: 手動更新資料 (每 10 秒自動更新)

## ⚙️ 策略邏輯說明

### 初始建倉
同時建立多倉和空倉，捕捉雙向行情

### 加倉規則
- **多倉**: 價格上漲達門檻 → 買入加倉 (最多 2 次)
- **空倉**: 價格下跌達門檻 → 賣出加倉 (最多 2 次)

### 平倉規則
當任一倉位獲利達標：
1. 自動平倉
2. 記錄獲利
3. 重新初始建倉

### 循環運作
平倉後自動重新建倉，持續運行

## ⚠️ 重要提醒

### 風險警告
1. 加密貨幣交易有風險
2. 雙向持倉會對沖，實際只賺手續費差
3. 震盪市場可能頻繁觸發交易
4. **請先用測試網熟悉操作**

### 資金管理
1. 初期使用小額資金測試
2. 不要投入無法承受損失的資金
3. 設定每日最大虧損限制
4. 定期提取獲利

### 系統監控
1. 保持程式運行環境穩定
2. 定期檢查日誌檔 `trading_bot.log`
3. 注意 API 請求頻率限制
4. 確保網路連線穩定

## 🐛 常見問題

### Q: 無法啟動機器人？
**A**: 檢查：
- API Key 和 Secret 是否正確
- 是否選擇了交易對
- 測試網是否有足夠餘額

### Q: 沒有收到 Telegram 通知？
**A**: 確認：
- Bot Token 格式正確
- Chat ID 正確
- 先在 Telegram 對機器人發送 `/start`

### Q: 載入合約失敗？
**A**: 
- 檢查網路連線
- 確認 API 地址正確
- 查看控制台錯誤訊息

### Q: 想停止交易怎麼辦？
**A**: 
- 點擊「⏹️ 停止機器人」
- 或關閉程式 (Ctrl+C)
- 建議手動平掉所有倉位
